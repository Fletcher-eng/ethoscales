What is Network State?

Network State is a political ideology in the Technological family. A network state begins as an online community with a shared moral purpose and a recognised founder. It organises collective action, crowdfunds territory around the world, and eventually seeks diplomatic recognition. Membership is opt in, recorded on a blockchain, and can be left at will.

Cloud first, land last.

Defined from: Balaji Srinivasan, The Network State (2022)
